# Rule 01: Docs Structure

> Protocol slice for tools that look under `.agent/rules/` (ADR 0012).
> Live agent protocol is repo-root `AGENTS.md`. If this file disagrees, `AGENTS.md` wins; fix this file in the same task.

1. Never place files directly under `docs/` (e.g. `docs/foo.md`).
   Use a subdirectory — `docs/guides/`, `docs/generated/`, `docs/specs/`, `docs/adr/`, `docs/tasks/`, `docs/memo/`, `docs/architecture/`, `docs/branches/`, `docs/reviews/` are the harness defaults.
   If none fits, the agent MAY create a new subdirectory that best describes the content.
2. `docs/generated/` is machine-generated by `k3dge sync` (Diátaxis Reference) — do not edit manually.
   `docs/guides/` and `docs/architecture/` are for human-authored guides.
   `docs/tasks/` is the single work container (idea → deferred → in-progress → done via Status field).
   `docs/tasks/` 顶层为活跃任务，`archive/` 目录不计入 Agent 开工扫描（非递归）。
   `docs/memo/` is for not-yet-actionable thoughts (fuzzy concepts / not-yet-landable / weakly-related flashes) — no schedule; promote to tasks when mature.
   `docs/branches/` is for archived failed branches — self-contained summary, survives retries.
   Violations are blocked by `k3dge check` (`DOCS_ROOT_DISALLOWED`).
