# Authoring

Copy `_template.md`. File only on explicit "memo this", or after the user agrees to park an unlandable idea. Scan is top-level `*.md`; `archive/` is off.

Structure gate is `docs/memo/.schema.json` (`k3dge check`) — it has **no** frontmatter/section
rules today, so `_template.md` 的四键（类型/念头/触发场景/Date）就是全部必填。归档件里常见的
`关联度`/`处置`/`原文锚点`/`归档日期`/`Superseded-by`/`Legacy note` 是**散文键**（人写的判断记录，
闸不要求、也不校验其存在）：新件要不要带由人定，别当成机检契约。
