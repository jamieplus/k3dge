# k3dge 给不懂代码的甲方讲解

**k3dge 是给 AI 程序员配的“工地监理 + 自动修复系统”**

您把活交给 AI 写代码，最头疼的不是它写得慢，而是——写着写着就“跑偏”了：接口改了文档没改、不同 AI 换着用各写各的、时间一长没人知道当初定的规矩是什么。k3dge 就是把“口头交代”变成“物理门禁”，让跑偏在提交代码那一刻就被拦住、并能一键修好。

## 1. 它解决什么问题

想象盖楼：
* **图纸（Spec）**说“大门宽 3 米”，**现场（代码）**却砌成了 2.5 米。过去靠监理口头喊，AI 听着听着就忘了。
* k3dge 把图纸变成带“防伪指纹”的合同，现场每砌一堵墙，机器自动比对指纹，指纹对不上，工地大门直接落锁，不让出场。

## 2. 一句话功能

**一次安装，长期不用管，AI 怎么换都不跑偏。**

* 人或 AI 按 README 点一下 `./k3dge-init.sh`，环境、钩子、目录就全建好。
* 以后 AI 改代码，门禁自动查；漏改文档，一键 `k3dge sync` 自动补齐；全程不用人反复提醒。

## 3. 三个核心零件（用人话）

| 零件 | 您怎么理解 | 在项目里是什么 |
| :--- | :--- | :--- |
| **图纸柜** | 每间房的“责任说明书+验收表” | `docs/specs/每个模块/spec.md`，写明这个模块管什么、不管什么、对外接口长什么样、怎么算合格 |
| **地址簿** | 哪块地归哪个施工队 | `.agent/manifest.json`，写明 `src/里哪段代码` 对应 `docs/里哪份图纸` |
| **门禁闸机** | 工地大门的刷卡机 | `scripts/gate.sh` + `k3dge check`，每次提交代码时自动跑，指纹不对直接红灯 |

**指纹怎么来？** 机器把代码里“对外接口”（比如大门叫什么名、要几个参数）提炼出来算一个 64 位指纹，存进图纸。以后代码变了指纹变，图纸没跟着变就被抓住——AI 想靠“在图纸上随便加个空格骗过去”没用。

## 4. 项目结构（像楼盘沙盘）

```
k3dge/
├── k3dge-init.sh          ← 一键开盘按钮，跑一次全建好（地基、通水电、挂门禁）
├── README.md              ← 给人看的售楼书，不会被机器瞎改；布局表由机器自动刷新
├── AGENTS.md              ← 给 AI 看的“工地纪律”（AI 实际会打开的入口）
├── .agent/                ← 给门禁进程的配置（隐藏目录，AI 不会自己逛到）
│   ├── manifest.json      ← 地址簿（哪段代码对应哪份图纸）
│   ├── rules/             ← 纪律切片（只有 AGENTS.md 点名时才读）
│   └── docs.toml          ← 收尾要写哪些给人看的说明书
├── docs/
│   ├── adr/               ← 决策日记：为什么这么盖，翻旧账用
│   ├── specs/             ← 图纸柜，每个模块一份
│   └── tasks/             ← 待办看板
├── scripts/gate.sh        ← 门禁闸机（免激活，自动找环境里的 k3dge）
└── src/k3dge/
    ├── engine/            ← 监理大脑：找改了哪些文件、算指纹、判是否一致
    ├── sync/              ← 自动修复：指纹变了，一键把图纸重画好
    └── templates/         ← 样板间：新楼盘一键复制整套图纸和门禁
```

## 5. 日常怎么转（闭环）

1. **开盘**：`./k3dge-init.sh`（人点或让 AI 照 README 点）
2. **施工**：AI 照图纸改 `src/` 里的代码
3. **过闸**：`git commit` 时 `k3dge check` 自动比对指纹
   * 绿灯 → 放行
   * 红灯 `CONTRACT_DRIFT：图纸指纹 ≠ 代码指纹，请跑 k3dge sync` → AI 看到机器报错，自己跑 `k3dge sync` 把图纸指纹刷新，再提交就过
4. **布局自愈**：`README` 里的“楼盘总表”也是机器从地址簿自动生成的，不用手维护

整个过程，**人不用盯着 AI 有没有忘改文档**，机器会拦、会报、会修。

## 6. 对甲方的价值

* **换 AI 不翻车**：今天用 Claude，明天换 Cursor，图纸和指纹在磁盘上，谁来都得按同一套过闸。
* **跨时间可追溯**：半年后打开图纸柜，就知道每个接口当初为什么这么定。
* **零打扰**：装一次，之后 AI 自律，失败超过两次才会让它 `git stash` 重来，不会乱打补丁把现场搞得更糟。

现在这套已可在团队内试点；要对外大规模推广，只差“上架应用商店”（发到 PyPI 让别人 `pip install k3dge` 一键装）这一步。
