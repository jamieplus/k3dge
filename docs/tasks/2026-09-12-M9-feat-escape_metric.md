# 逃逸率/趋势度量：触发口径 + 观测行

- **Status**: idea
- **Milestone**: M9
- **Priority**: P2

## Intent
把"逃逸"变成可数事实：后续里程碑发现的**上轮漏项**比率，进观测行（不阻断提交）。

- 事实归属：逃逸真值＝后续里程碑发现对前序的漏项；账归 k3dit；触发口径归 k3dge。
