# 契约哈希含文件名，重命名会误报漂移

- **Status**: done
- **Milestone**: M1
- **Priority**: P1
- **Date**: 2026-08-25

## 已确认意图
`collect_domain_interface` 拼 `# {file_path.name}` 再哈希。签名不变只改文件名，Contract Hash 变。违背 overview「只锁公开签名」。Pass 4 P4-04 是同一条，不另开单。

## 方案
哈希路径去掉文件名行（或只对 `include_doc=True` 的展示流保留）。`k3dge sync` 重算四域哈希。补 `test_contract_rename_preserves_hash`。
