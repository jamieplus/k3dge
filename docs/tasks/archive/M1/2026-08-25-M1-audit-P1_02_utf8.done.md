# spec/milestone/version 读盘未包 UnicodeDecodeError

- **Status**: done
- **Milestone**: M1
- **Priority**: P1
- **Date**: 2026-08-25

## 已确认意图
Pass 1 写「四处均崩」过满：契约抽取已把 `UnicodeDecodeError` 收成 `_ExtractError`。仍裸抛的是 spec / milestone 任务文件 / version 的 `read_text(encoding="utf-8")`。坏字节应变成 `Violation`，不能让 `evaluate` traceback。

## 方案
在 `evaluator._check_domain` 读 spec、`milestone` 扫 tasks、`version.get_*` 读文本处捕获 `UnicodeDecodeError`，记 `SPEC_NOT_UTF8` / `MANIFEST_INVALID` / 同等 rule。不要改已经包装过的 `contract.extract`。补测：spec 写入 `b"\\xff"` 后 `evaluate(force_full=True)` 返回违规而非异常。

## 入口
- `src/k3dge/engine/evaluator.py` 读 spec
- `src/k3dge/engine/milestone.py` 读 tasks
- `src/k3dge/engine/version.py` `read_text`
- `src/k3dge/engine/manifest.py` `load`（若仍裸 `open` utf-8）
