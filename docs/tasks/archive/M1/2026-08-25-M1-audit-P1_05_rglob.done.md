# rglob 跟随符号链接，外链文件可进哈希

- **Status**: done
- **Milestone**: M1
- **Priority**: P1
- **Date**: 2026-08-25

## 已确认意图
`collect_domain_interface` 用 `src_dir.rglob("*")` + `is_file()`，符号链接指向域外 `.py` 会被抽取进契约。

## 方案
跳过 `is_symlink()`；若 Python 版本支持，`rglob(..., follow_symlinks=False)`。补测：域内 symlink 指向仓外文件，不得出现在 interface 字符串。

## 入口
- `src/k3dge/engine/contract.py` `collect_domain_interface`
