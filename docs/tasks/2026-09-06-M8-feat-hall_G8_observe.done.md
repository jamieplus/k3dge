# G8: 进程侧观测（统计席位+逃逸率+观测行）

- **Status**: done
- **Milestone**: M8
- **Priority**: P2
- **可检索摘要**: 统计席位（程序控制+收尾度量+回归测试）落 Hall 进程侧（不占判读窗、无签名钥）：逃逸率/误诊率/窗口漂移只进通告牌与观测行、不进闸；归属裁决见 ADR-0025 §2.4
- **Date**: 2026-09-06

## Intent

观测面是进程侧职责（确定性程序控制 + 只出事实不判定），与判读窗彻底分开。

## Notes

- 内容：统计席位（程序控制+收尾度量+回归）+ 逃逸率/误诊率/窗口漂移度量 + status 观测行。
- 纪律：观测不判定、不中途改单，作用于下一单/下一轮校准（沿 hall-pattern memo §3 度量回灌）。
- 度量口径（逃逸率定义、窗口漂移阈值）是方法论，下一步讨论，本 task 只搭管线。

## 边界与拆分（feat 类必填；规则 08）

- 事实归属：度量数字属进程侧；口径定义属方法论（待定）；判读窗只消费观测、不自算。
- 边界检查：观测不写账本、不碰闭包计数；进程侧不判内容。
- 桩子先行：先观测行 + 通告牌字段（静态输出），再接统计席位数据源。
