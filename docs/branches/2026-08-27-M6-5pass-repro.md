## 详细 B-T-D（代表：P1-01 / P3-01 / P1-04）

### P1-01 — CHANGELOG 静默

- **Baseline**:
  ```bash
  .venv/bin/python -c "
  import pathlib, tempfile; from pathlib import Path; from k3dge.engine.milestone import _append_to_unreleased
  tmp=Path(tempfile.mkdtemp()); (tmp/'CHANGELOG.md').write_text('# Changelog\n\n## [Unreleased]\n', encoding='utf-8')
  (tmp/'docs/tasks').mkdir(parents=True); t=tmp/'docs/tasks/2026-08-27-M6-fix-test.md'; t.write_text('# Fix\n\n- **Status**: idea\n', encoding='utf-8')
  orig=Path.write_text; Path.write_text=lambda s,*a,**kw: (_ for _ in ()).throw(OSError('disk full')) if 'CHANGELOG' in str(s) else orig(s,*a,**kw)
  import sys,io; sys.stderr=io.StringIO(); r=_append_to_unreleased(tmp,t); o=sys.stderr.getvalue(); sys.stderr=sys.__stderr__; Path.write_text=orig
  print(r, repr(o))  # Baseline: r=None, o=''
  "
  # → r=None, o='' (静默)
  ```
- **Treatment**（同命令修复后）: `r=False, o='[WARN] _append_to_unreleased failed for 2026-08-27-M6-fix-test.md: disk full\n'`，`mark_task_done` 亦 `[WARN] mark_task_done: CHANGELOG update failed`
- **Design**: `except:pass` 改 `except as exc: print WARN + return False`

### P3-01 — seal 双轨

- **Baseline**: `diff -u <(sed -n '340,355p' cli/main.py) <(sed -n '314,325p' mcp.py)` 显示 `cli` 用 `Unreleased`、`mcp` 用 `archive`
- **Treatment**: `version.py:253 consume_unreleased` 后双轨同 `body=consume_unreleased(ws) or f"Seal {id}"`，`git diff cli/main.py mcp.py` 均调同一函数
- **Design**: 双轨必共享 `consume_unreleased`

### P1-04 — .mcp.json 损坏

- **Baseline**: `echo '[' > .mcp.json; .venv/bin/python -c "from k3dge.templates.scaffold import _ensure_mcp_config; print(_ensure_mcp_config(Path('.')))"` → `None` 无 `stderr`
- **Treatment**: `ensure_mcp_config(Path(tmp))` → `False` + `[WARN] .mcp.json corrupted ...`
- **Design**: 损坏不静默，`bool+WARN`

## 学到什么（下次避坑）

- `except:pass` 在 `CHANGELOG` 侧必 `WARN` 或 `bool`；`rg "except.*: pass"` 0 容忍
- 公有/私有边界：`_private` 不跨域，晋升需 `k3dge sync`
- 双轨 `seal` 必抽 `consume_unreleased`，`rg "consume_unreleased"` 双命中校验
- 矩阵与闸面同增：新增 `guide-stub`/`Unreleased`/`pipeline` 即补 `TC-*`
- `§5.1` 单一事实源：`SUMMARY.md` 常驻表为准，`overview.md` 仅索引
