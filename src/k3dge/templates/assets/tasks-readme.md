# Tasks — work register

Single work-item container. Not `docs/memo/` (sparks) and not `docs/branches/` (falsified attempts).

- **Address**: `k3dge task list --json` or `k3dge doc list --type tasks`. Then `read` hits only. Archive is off the scan surface.
- **Write**: read [`AUTHORING.md`](AUTHORING.md); `k3dge task create` or copy [`_template.md`](_template.md).
